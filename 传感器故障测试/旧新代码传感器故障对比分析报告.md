# 旧版与新版车辆纵侧向速度估计算法对比分析报告

## 1. 报告目的与结论边界

本报告基于以下实际产物进行整理：

- 旧版原始结果：`旧代码/quick_512_manual_server/`
- 旧版严格分析：`旧代码/quick_512_manual_analysis/`
- 新版原始结果：`新代码/quick_512_manual_server/`
- 新版严格分析：`新代码/quick_512_manual_analysis/`
- 新版正常工况 Stage-1 结果：seed 42、17,091 个 nuScenes 样本、75 个场景

两次 quick-512 的样本集合并不完全相同，因此不能直接把两份 512 样本总体均值作为严格的前后对照。本报告以 `scene_name + center_token` 对齐，只比较两版共同包含、且速度标签完全一致的 257 个样本和 38 个场景。

当前新版结果仅代表：

- nuScenes 固定划分；
- seed 42；
- `ego_reference` 参考点速度；
- 视觉主线与弱运动学分支；
- 开环、合成传感器故障测试。

不能据此宣称跨 seed 稳定性、车辆质心速度验证、真实传感器故障鲁棒性或完整动力学融合已经完成。

## 2. 旧版算法及测试发现

### 2.1 旧版结构特征

旧版 VKD 模型采用视觉、运动学和动力学代理特征共同回归速度。实际 quick-512 结果显示，模型在正常 CAN 输入下精度较高，但输出高度依赖底盘/CAN 信息，视觉分支的实际贡献较弱。

### 2.2 已测试的故障与特殊工况

旧版测试包含以下五种工况：

| 工况 | 故障含义 |
| --- | --- |
| `clean` | 无注入故障 |
| `can_missing` | CAN 信号全部缺失 |
| `yaw_bias_pos` | 横摆角速度增加 `+0.02 rad/s` 偏置 |
| `wheel_scale_low` | 四轮轮速统一缩放至原值的 `0.9` |
| `camera_missing` | 相机图像全部置空 |

### 2.3 旧版完整训练结果与消融

旧版算法说明中的全量验证结果覆盖 33,148 个对齐样本：

| 旧版方法 | EPE | MAE vx | MAE vy |
| --- | ---: | ---: | ---: |
| 视觉 + 运动学 + 动力学代理 | 0.07438 | 0.06875 | 0.01782 |
| 运动学 + 动力学代理 | 0.07559 | 0.06995 | 0.01784 |
| 视觉 + 运动学 | 0.07625 | 0.07049 | 0.01815 |
| 纯视觉 | 1.08914 | 1.08815 | 0.02150 |

这组结果说明：

1. 旧版完整模型在单 seed 消融中表现最好；
2. 在“视觉 + 运动学”上增加动力学代理后，EPE 从 `0.07625` 降到 `0.07438 m/s`，相对改善约 `2.45%`；
3. 动力学分支有收益，但收益有限，不能解释当前新版与旧版之间的大部分精度差距；
4. 纯视觉误差为 `1.08914 m/s`，加入运动学后降到 `0.07625 m/s`，说明旧版性能主要来自底盘/运动学信息，而不是视觉主体；
5. 旧版输出采用 `[base_vx, 0] + residual`，运动学输入直接包含车速、里程计速度、四轮轮速、轮速均值和 `base_vx`；动力学代理又使用 `base_vx`、yaw、加速度等重复信息。因此旧版存在非常强的底盘先验和特征重复。

### 2.4 旧版暴露的问题

在前后共同的 257 个样本上，旧版 VKD 的结果为：

| 工况 | 旧版 EPE | 相对旧版 clean 的退化 |
| --- | ---: | ---: |
| clean | 0.08068 m/s | - |
| CAN 全部缺失 | 5.04327 m/s | +4.96260 m/s |
| yaw 正偏置 | 0.08053 m/s | -0.00015 m/s |
| 轮速缩放 0.9 | 0.09199 m/s | +0.01131 m/s |
| 相机全部缺失 | 0.08305 m/s | +0.00238 m/s |

旧版最明确的问题是：

1. **CAN 全部缺失时发生灾难性退化。** EPE 从 `0.08068` 增长到 `5.04327 m/s`，说明速度主体主要由底盘/CAN 决定。
2. **相机缺失几乎不改变输出。** 相机全部置空仅增加约 `0.00238 m/s`，表明旧版视觉分支对最终结果的实际影响很弱。
3. **存在底盘捷径风险。** 正常工况精度很高，但结合 CAN 缺失和相机缺失结果，更符合“模型主要依赖底盘直接映射”的特征，而不是视觉证据主导的速度估计。
4. yaw 偏置影响接近零，但仅凭这一结果不能证明 yaw 补偿鲁棒，也可能是 yaw 路径贡献不足。

## 3. 针对旧版问题的算法改造

新版按照《视觉-运动学-动力学辅助车辆纵侧向速度估计技术研究思路（修订版 V2）》进行重构，核心不是继续堆叠三个回归分支，而是将速度主体改为视觉弱几何估计，底盘信息仅作受限辅助。

### 3.1 视觉几何主线

新版首先构造视觉主体速度：

$$
\mathbf v_{\mathrm{visual}}
=
\begin{bmatrix}
s_w v_{x,\mathrm{geo}} \\
v_{y,\mathrm{geo}}
\end{bmatrix}
+
g_{\mathrm{img}}\Delta\mathbf v_{\mathrm{img}}.
$$

实际结构包括：

1. 连续前视 RGB 图像与 RAFT 光流；
2. 利用 yaw rate 构造旋转光流并进行去旋转补偿；
3. 在道路 ROI 上提取平移残差流；
4. 结合相机高度、内参和道路平面，通过 IRLS 求解公制几何速度；
5. 输出条件数、协方差、残差和支持点数，用于几何有效性判断；
6. 轮速绝对值仅进入 `±15%` 的受限纵向尺度分支；
7. 图像网络只输出有界视觉残差，不能直接推翻几何主体。

这一结构直接针对旧版“底盘信号决定最终速度”的问题：即使 CAN 缺失，视觉与光流仍保留独立的速度估计能力。

### 3.2 弱运动学分支

新版弱运动学编码器采用 1 秒、20 Hz、21 步严格因果序列：

```text
[B, 21, 36]
 -> Linear(36, 64) -> ReLU -> Linear(64, 64)
 -> causal GRU(hidden=128)
 -> bounded delta_v_kin
 -> uncertainty and gate
```

最终输出为：

$$
\hat{\mathbf v}
=
\mathbf v_{\mathrm{visual}}
+
g_{\mathrm{kin}}\Delta\mathbf v_{\mathrm{kin}}.
$$

其中：

- 运动学校正限幅为 `[1.0, 0.5] m/s`；
- 门控由有效覆盖率和预测不确定性控制；
- 四轮绝对速度均值不进入 GRU，只允许进入受限尺度和失效回退；
- 输入包含有效掩码与报文年龄，避免把缺失值伪装成正常信号；
- 不允许 pose 派生速度、加速度或旋转率进入运动学编码器。

### 3.3 当前已完成范围

当前完成的是：

- 视觉弱几何主体；
- 有界视觉残差；
- 弱运动学时序编码器；
- visual 与 visual-kinematic 的 nuScenes 训练和 seed-42 初步评估。

尚未完成动力学教师/学生分支和最终三分支融合，因此当前不能称为完整的视觉-运动学-动力学算法。

### 3.4 为什么当前新版的最终指标看起来反而更差

当前新版不是与旧版成熟度相同的完整模型，而是 V2 路线的第一阶段中间版本。旧版 VKD 已同时使用视觉、运动学和动力学代理信息，并允许较强的底盘直接映射；当前新版只完成了视觉主线和弱运动学编码器，动力学教师/学生尚未训练和接入。因此，两者当前不是功能完整度对等的模型。

动力学分支缺失会直接影响以下误差的补偿能力：

- 轮胎侧向力和纵向力变化；
- 车辆侧偏、滑移和附着变化；
- 载荷转移及转向瞬态；
- 制动转向、蛇形和双移线等强动态工况；
- 仅靠视觉几何和弱运动学序列难以解释的非线性残差。

与此同时，新版为了避免旧版的底盘捷径，主动限制了底盘信息的使用：轮速绝对值不能进入 GRU，运动学分支只能输出有界残差。这使当前阶段失去了旧版依靠底盘直接回归获得的部分 clean 精度，但也换来了 CAN 完全缺失时不再整体崩溃的能力。

但是，旧版消融已经证明动力学代理只将 EPE 从 `0.07625` 改善到 `0.07438 m/s`，约为 `2.45%`。所以动力学分支尚未训练可以解释新版“尚不是完整 V2”，却不能单独解释当前一个数量级的 clean 精度差距。

当前结果看起来更差，应由以下因素共同解释：

1. 动力学教师/学生和最终融合尚未完成；
2. 新版主动移除了旧版 `[base_vx,0] + residual` 和绝对轮速直接进入编码器的底盘捷径；
3. 当前视觉弱几何主体尚未达到旧版强底盘先验的 clean 精度；
4. 当前还存在轮速尺度饱和、yaw 路径作用弱和相机 fallback 输出错误。

因此更准确的表述是：

> **当前只训练完成“视觉 + 弱运动学”，尚缺少动力学分支和最终融合微调；但旧版消融表明动力学代理收益只有约 2.45%，当前较大差距主要还来自底盘捷径被移除、视觉主体尚未成熟和已知实现缺陷。当前结果属于中间阶段，不是完整 V2 的最终性能。**

必须强调，不能把全部差距都归因于动力学分支尚未训练。旧版动力学代理本身与运动学特征重复，而且没有显式物理约束。新版动力学教师/学生的目标应是补充侧偏、附着和瞬态等旧代理未有效表达的信息，而不是重新引入 `base_vx` 捷径。

## 4. 前后对齐结果

### 4.1 同 token 对照结果

| 工况 | 旧版 VKD EPE | 新版 Joint EPE | 旧版故障退化 | 新版故障退化 | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| clean | 0.08068 | 1.02116 | - | - | 新版正常精度明显更差 |
| CAN 全部缺失 | 5.04327 | 1.36724 | +4.96260 | +0.34608 | 新版 CAN 失效退化显著减小 |
| yaw 正偏置 | 0.08053 | 1.02454 | -0.00015 | +0.00338 | 无优化证据，新版略差但绝对变化很小 |
| 轮速缩放 0.9 | 0.09199 | 1.02116 | +0.01131 | 0.00000 | 不能认定鲁棒，结果受尺度下限饱和掩盖 |
| 相机全部缺失 | 0.08305 | 7.96081 | +0.00238 | +6.93964 | 新版严重退化，回退路径存在缺陷 |

单位均为 `m/s`。

### 4.2 唯一能够明确成立的优化效果

CAN 全部缺失时：

- 旧版 EPE：`5.04327 m/s`；
- 新版 EPE：`1.36724 m/s`；
- 故障状态绝对 EPE 降低约 `72.9%`；
- 相对各自 clean 的故障退化从 `4.96260` 降至 `0.34608 m/s`；
- 以场景为单位，故障退化差 `新版 - 旧版` 为 `-4.58574 m/s`；
- 场景 bootstrap 95% CI 为 `[-5.61687, -3.56135] m/s`。

该区间完全小于零，说明在当前共同样本中，**将速度主体改为视觉几何主线，确实显著降低了模型对完整 CAN 的依赖**。这一结果能够落到算法结构优化上：旧版 CAN 丢失后主体信息消失，而新版仍保留图像、光流、道路几何和有界视觉残差提供的独立估计。

### 4.3 不能回避的负面结果

1. **新版 clean 精度没有超过旧版。** 同 token 下新版 EPE 为 `1.02116 m/s`，旧版为 `0.08068 m/s`。因此不能宣称新版整体精度优于旧版。
2. **新版相机缺失退化严重。** 同 token 下相机缺失 EPE 为 `7.96081 m/s`，明显差于旧版。
3. **fallback 标志与最终输出路径不一致。** 新版 512 样本相机缺失测试中：
   - `geometry_invalid=1`：512/512；
   - `fallback_used=1`：512/512；
   - 可用基础轮速均值：`5.15555 m/s`；
   - 最终预测 vx 均值：`-2.75285 m/s`。

   即失效检测和回退标志已触发，但最终输出没有采用可用基础轮速。这是明确的实现缺陷。
4. 轮速缩放测试的零变化不能解释为鲁棒性。完整 holdout 中约 `82.6%` 样本的轮速尺度已经位于下限 `0.85`，`0.9` 扰动被限幅饱和掩盖。
5. V2 yaw 路径和视觉门控贡献仍需核查；现有近零敏感性可能是路径作用弱，而不是鲁棒。

当前 clean 差距应解释为“中间阶段结构尚未完整 + 主动移除底盘捷径 + 已知实现问题”的共同结果，而不能简单解释为最终 V2 方案不如旧版，也不能在动力学分支尚未训练时给出完整路线的最终结论。

## 5. 新版内部有效性证据

在新版完整 Stage-1 holdout 上，使用正确的 accelerated checkpoint：

| 模型 | EPE | vx MAE | vy MAE |
| --- | ---: | ---: | ---: |
| visual | 0.72275 | 0.52282 | 0.31476 |
| visual + weak kinematic | 0.64464 | 0.47144 | 0.26884 |

弱运动学分支相对 visual：

- EPE 改善 `10.81%`；
- vx MAE 改善 `9.83%`；
- vy MAE 改善 `14.59%`；
- 75 个场景中 68 个场景改善。

这能够支持：**在当前新版结构内部，有界弱运动学校正确实改善了视觉主线的速度估计。** 但该结论仍限于 seed 42 和 nuScenes 固定划分。

## 6. 总体判断

当前结果不能支持“新版全面优于旧版”，但可以支持一个更准确的工程结论：

> 旧版依赖底盘/CAN 直接映射，正常工况精度高，但 CAN 完全缺失时发生灾难性失效。新版通过建立视觉弱几何主体并将运动学限制为有界残差，使 CAN 完全缺失时的故障退化显著下降，证明降低底盘依赖的结构改造在这一故障上有效；与此同时，新版正常精度仍不足，并暴露出相机失效回退未真正进入最终输出的严重缺陷。

当前新版应被定义为“V2 第一阶段验证模型”，而不是最终完整模型。待动力学教师/学生、最终融合门控和整体微调完成后，才能与旧版完整 VKD 进行最终精度和鲁棒性比较。

## 7. 下一阶段计划

### 7.1 先修复当前结构缺陷

1. 修复相机失效时的最终 fallback 输出路径，确保 `fallback_used` 真正选择 `[v_w, 0]`；
2. 修复轮速尺度长期卡在 `0.85` 下限的问题，重新审计尺度标定；
3. 审计 yaw 补偿和视觉残差门控是否实际工作；
4. 统一 legacy 与 V2 的 CAN 时间对齐和场景元数据；
5. 后续补做 CAN stale/dropout、相机冻结和轮速正偏等未运行测试。

### 7.2 训练动力学教师/学生分支

下一步将在视觉主线和弱运动学分支基础上增加动力学分支：

1. 使用 CarSim 或其他高保真仿真构造动力学教师；
2. 覆盖转弯、蛇形、双移线、制动转向、不同附着系数、载荷和轮胎参数；
3. 教师侧可使用仿真可观测的质心速度、侧偏角、横摆响应、轮胎力或滑移状态；
4. 将教师知识蒸馏到不依赖完整车辆参数的轻量动力学学生；
5. 动力学学生只提供受不确定性约束的辅助残差，不能替代视觉主体。

### 7.3 最终融合与实车/仿真联合微调

未来需采集或生成严格同步的数据：

- 前视图像/视频；
- IMU 角速度与加速度；
- 转向、四轮轮速、油门和制动；
- 动力学状态或高精度速度参考；
- 相机、IMU、车辆参考点的时间同步和空间标定。

数据可以来自实车，也可以来自带相机和底盘动力学联合输出的仿真，但必须保证视觉帧与运动学、动力学信号严格对齐。随后训练最终融合模块，并对视觉、弱运动学、动力学学生和融合门控进行整体微调。最终再使用独立实车数据验证泛化能力和真实故障降级行为。
