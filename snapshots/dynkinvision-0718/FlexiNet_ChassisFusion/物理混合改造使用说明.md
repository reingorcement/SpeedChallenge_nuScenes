# 物理混合速度估计使用说明

## 主配置

机理-数据混合主配置为：

```text
configs/velocity_xy_vision_chassis_physics.yaml
```

模型使用历史图像、历史 `fair_chassis` 和因果物理估计器，输出车体坐标系二维速度 `[vx, vy]`：

```text
pred = physics_prior + correction_gate * learned_delta
```

原 `default.yaml` 保持兼容，不会自动切换到物理模式。

## 单位审计

物理配置默认设置：

```yaml
data:
  physics_units_audited: false
```

训练、测试、分析和 profile 会拒绝运行未审计的物理配置。先运行：

```bash
python scripts/audit_eovm_inputs.py \
  --can_bus_root /path/to/nuscenes/can_bus \
  --scene_name scene-0061
```

确认四轮速度 `/1000` 后为 `m/s`、转向字段符号和比例、横摆率为 `rad/s`、纵横向加速度为 `m/s^2` 后，才将 `physics_units_audited` 改为 `true`。

## 完整物理信号

可选 `physics_extra_root` 指向按场景保存的 CSV 目录。文件名为 `scene-XXXX.csv`，必须包含 `timestamp_us`，其余列可部分提供：

```text
wheel_torque_fl, wheel_torque_fr, wheel_torque_rl, wheel_torque_rr,
tire_fx_fl, tire_fx_fr, tire_fx_rl, tire_fx_rr,
normal_load_fl, normal_load_fr, normal_load_rl, normal_load_rr,
reverse_enable, rear_drive_enable, road_friction
```

每个时间点使用不晚于当前时间的最近一行，保证在线因果性。缺失列通过 `physics_valid_mask` 标记为无效，不会把零值当成测量。

CAN 与完整物理信号分别使用以下最大时延：

```yaml
data:
  can_max_age_sec: 0.25
  physics_extra_max_age_sec: 0.5
```

超过最大时延的旧记录会被标记为无效，不会无限保持上一测量。

## 消融配置

```text
velocity_xy_base.yaml                    现有底盘基准
velocity_xy_chassis_only.yaml            原始底盘时序网络
velocity_xy_vision_only.yaml             视觉网络
velocity_xy_vision_kinematics.yaml       视觉 + 底盘
velocity_xy_physics_only.yaml            物理估计器
velocity_xy_physics_feature_only.yaml    物理估计器 + 物理特征 GRU
velocity_xy_vision_chassis_physics.yaml  视觉 + 底盘 + 物理混合
```

所有配置使用因果底盘窗口。物理 smoke 配置为 `configs/smoke_velocity_xy_physics_hybrid.yaml`。

## 快速验证

不依赖 nuScenes 数据的模型 smoke：

```bash
python smoke_model.py --with_physics --batch_size 2 --seq_len 3
```

代码测试：

```bash
python -m pytest tests eovm_ekf/tests -q
```

真实数据 smoke 在完成单位审计并修正配置路径后运行：

```bash
python train.py --config configs/smoke_velocity_xy_physics_hybrid.yaml
```
