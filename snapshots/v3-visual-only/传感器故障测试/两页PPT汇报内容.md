# 两页 PPT 汇报内容

## 第 1 页：传感器故障测试与算法优化效果

### 标题

**从底盘依赖到视觉主导：旧版问题、V2 改造与故障测试结果**

### 测试设计

- 故障工况：CAN 全部缺失、yaw rate `+0.02 rad/s` 偏置、轮速 `0.9` 缩放、相机全部缺失。
- 为避免两次 quick-512 样本不一致，只比较两版共同的 **257 个 token、38 个场景**。
- 指标：纵侧向速度端点误差 EPE，单位 `m/s`；场景为统计单位。

### 旧版问题

- 旧版正常 EPE：`0.081`，但 CAN 缺失后升至 `5.043`。
- 相机缺失仅升至 `0.083`，说明旧版主要依赖底盘/CAN，视觉实际贡献弱。
- 核心问题：**底盘捷径明显，CAN 丢失时速度主体失效。**

旧版全量消融：

| 旧版结构 | EPE |
| --- | ---: |
| 视觉 + 运动学 + 动力学代理 | 0.0744 |
| 视觉 + 运动学 | 0.0763 |
| 纯视觉 | 1.0891 |

动力学代理带来约 `2.5%` 收益；旧版主要优势来自 `[base_vx,0] + residual` 和直接底盘速度输入。

### V2 结构改造

```text
图像 + RAFT光流
 -> yaw去旋转 + 道路平面 + IRLS弱几何速度
 -> 有界视觉残差
 -> 1 s因果GRU弱运动学校正（限幅+不确定性门控）
 -> vx, vy
```

- 最终速度主体来自视觉几何；轮速只提供受限尺度。
- 弱运动学只输出 `[1.0, 0.5] m/s` 内的残差，绝对轮速不进入 GRU。

### 共同样本结果

| 工况 | 旧版 EPE | 新版 EPE | 判断 |
| --- | ---: | ---: | --- |
| clean | 0.081 | 1.021 | 新版正常精度仍不足 |
| CAN 全部缺失 | 5.043 | 1.367 | **故障 EPE 降低 72.9%** |
| yaw 正偏置 | 0.081 | 1.025 | 无明确优化证据 |
| 轮速缩放 0.9 | 0.092 | 1.021 | 被尺度饱和掩盖，不能称鲁棒 |
| 相机全部缺失 | 0.083 | 7.961 | 新版 fallback 输出路径存在缺陷 |

### 为什么当前新版指标看起来更差

- 旧版已包含视觉、运动学和动力学代理，并依靠较强底盘直接映射获得较高 clean 精度。
- 当前 V2 **只完成视觉 + 弱运动学训练，动力学教师/学生尚未训练，最终融合尚未微调**。
- 新版主动限制底盘捷径：绝对轮速不进入 GRU、运动学只能输出有界残差，因此当前阶段不能直接复现旧版的底盘回归精度。
- 旧版消融表明动力学代理收益仅约 `2.5%`，所以动力学缺失不是全部原因；视觉精度、尺度饱和和相机 fallback 缺陷仍需修复。

### 本页结论

**视觉主导改造显著降低了 CAN 完全缺失时的退化：故障退化从 `4.963` 降至 `0.346 m/s`，场景 bootstrap 95% CI 为 `[-5.617, -3.561]`。该优化对“降低 CAN 依赖”有效；当前较差的 clean 结果来自“动力学分支未完成、旧版底盘捷径被移除、视觉主体未成熟和已知实现问题”的共同影响，不能只归因于动力学未训练。**

## 第 2 页：下一步计划 - 动力学分支与最终融合

### 标题

**从视觉 + 弱运动学扩展到视觉-运动学-动力学完整融合**

### 当前完成状态

- 已完成 nuScenes 上的视觉弱几何主线和弱运动学 GRU 训练。
- 新版完整 holdout：visual EPE `0.723`，visual + weak kinematic EPE `0.645`，改善 `10.8%`。
- 当前结果仍是 seed 42、`ego_reference` 速度，不是完整动力学或车辆质心速度验证。
- 当前版本是 V2 第一阶段中间模型；完成动力学教师/学生和最终融合微调后，才与旧版完整结构进行最终比较。

### 近期必须修复

1. 修复相机缺失时 `fallback_used=1` 但最终输出未采用轮速基准的问题。
2. 处理 `82.6%` 样本轮速尺度卡在 `0.85` 下限的尺度饱和。
3. 核查 yaw 补偿和视觉门控的真实贡献。
4. 统一视觉、legacy 和 V2 的 CAN 时间对齐及场景元数据。

### 动力学教师/学生训练

```text
CarSim/高保真仿真动力学真值
 -> 动力学教师（侧偏、横摆、轮胎/附着状态）
 -> 知识蒸馏
 -> 轻量动力学学生残差分支
```

- 工况：稳态圆周、蛇形、双移线、制动转向、不同附着/载荷/轮胎参数。
- 动力学学生只作有界辅助，不替代视觉速度主体。
- 目标不是复刻旧版重复使用 `base_vx` 的动力学代理，而是学习侧偏、附着和瞬态等视觉/弱运动学难以表达的残差。

### 最终融合与验证

- 采集实车或联合仿真数据，必须保证：**图像、IMU、转向、四轮轮速、油门/制动及动力学参考严格时间同步和空间标定**。
- 训练最终融合门控，对视觉、弱运动学、动力学学生进行整体微调。
- 最终使用独立实车数据、多 seed 和分级传感器故障验证。

### 本页结论

**下一阶段不是重新推翻视觉主线，而是在修复现有降级路径后，引入动力学教师/学生作为受限辅助，最后利用视觉与底盘动力学严格对齐的实车或仿真数据完成融合训练和整体微调。**
