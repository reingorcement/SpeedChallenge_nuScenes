## 1. 目标、边界与成功标准

### 1.1 最终任务

推理使用车载单目图像及其允许的派生信息，输出指定车体参考点 O 的速度：

$$
\hat v_O^b(t)=[\hat v_x(t),\hat v_y(t)]^\top,
$$

其中 x 轴前向、y 轴左向，单位 m/s。必须同时声明参考点、坐标系与时间语义，不能只写“车辆速度”。

推理输入允许：

- 同一台相机的历史及当前图像。
- 由这些图像计算的光流、分割、深度或视觉姿态，启用时须计入计算成本。
- 图像时间戳、相机固定标定，以及任务允许的固定安装高度／地面先验。

推理不读取 IMU、CAN、GNSS、实时激光雷达，也不使用测试真值修正尺度、姿态、时间偏移或选择输出。不研究路侧监控测速。

训练和离线评价可使用其他传感器形成的真值，但应逐字段登记用途。训练时使用真实旋转构造损失仍可满足推理纯视觉，必须说明它属于额外训练信息。

### 1.2 研究问题

1. 在相同图像、时间范围和训练预算下，显式光流表示是否提高速度回归的精度、样本利用或泛化？
2. 收益主要来自运动表示、更多容量、预训练先验、训练策略，还是更长的时间信息？
3. 单独光流编码、可靠性提示和时序结构，分别解决了什么已观察到的问题？
4. 误差是否主要来自尺度、旋转混淆、地面假设或标签处理？
5. 条件齐全时，几何约束能否改善独立场景中的纵、侧向误差？

光流是同一视觉观测的派生表示，不称为增加了独立传感器信息。各模块有文献动机，不预设一定有效。[R1—R7]

### 1.3 保留三条路线

| 路线 | 计算过程 | 用途 |
| --- | --- | --- |
| A：图像学习 | 图像序列 → 定义明确的时序模型 → 一组二维速度 | 基线与容量对照 |
| B：图像＋光流学习 | 图像／光流特征 → 特征融合 → 一组二维速度 | 主要学习路线 |
| C：光流前端＋几何求解 | 光流＋时间＋标定／尺度先验 → 运动求解 → 二维速度 | 并行诊断与独立基线 |

路线 C 的光流前端可以是冻结 RAFT，因此不称整条路线“完全无学习”。几何损失是路线 B 的可选训练扩展。

**不引入 RGB、光流各自输出速度再融合两个速度预测的 B3。** 辅助旋转预测头不属于两个速度预测器融合，但其容量与监督需要对照。

### 1.4 模块保留标准

在 S0 确定主要指标、可接受复杂度和首轮选模规则。最小有意义改善幅度有依据时预先设定；缺少依据时，可用首轮训练估计波动，再在后续确认实验前锁定。探索结果不能同时充当事后设定标准的确认性证据。

- 新增方案只有优于定义一致的图像基线、满足关键工况约束时，才作为改进方案；分别说明纵向、侧向收益及退化。若无候选通过，交付图像基线和可信的无增益结论，不宣称已取得算法改善。
- 不能只凭总体二维误差下降，接受关键侧向工况显著恶化的方案。
- 结构初筛可用单种子；最终候选默认补充至少 3 个随机种子，资源不足时如实降低结论强度。
- 报告逐场景成对误差差值及不确定性；训练随机性与场景采样波动分开。
- 无稳定收益的模块可以撤销。阶段完成意味着获得可信结论，不意味着必须证明新模块有效。
- 验证集决定结构、超参数、阈值和权重；锁定后独立测试集只用于最终评价。

## 3. 数据、标签与输入契约

### 3.1 两种标签模式必须分开

| 模式 | 定义与适用条件 | 可以形成的结论 |
| --- | --- | --- |
| `BODY_3D` | 目标参考点在真实车体坐标系中的速度分量；完整位置、姿态及参考点转换具有可信依据 | 可研究最终体轴速度目标；仍需说明标签误差 |
| `PLANAR_PROXY` | 由平面位姿产生、以明确航向系表达的二维速度代理标签 | 只能声称对应的平面任务结果，不能自动推广到真实三维体轴／质心侧滑 |

若使用 nuScenes 官方平面位姿生成标签，先按 `PLANAR_PROXY` 管理。其 `ego_pose` 定位为 x–y 平面、z 恒为 0；应用完整四元数不能补回缺失的垂向运动。[R8] 若要切换到 `BODY_3D`，须另行验证完整运动标签和转换。**最终目标不因代理实验方便而自动改变；代理结果也不等于最终目标已经完成。**

每份标签记录：坐标轴、参考点 O、单位、差分／拟合公式、姿态取值时刻、区间长度、瞬时／平均／twist 语义、平滑窗口、杆臂处理和版本哈希。

### 3.2 图像与光流窗口

在线预测到时刻 t 为止，图像窗口为：

$$
I_{t-T+1},\ldots,I_t.
$$

相邻前向光流：

$$
F_{k\to k+1}=(u_k,v_k),\qquad k=t-T+1,\ldots,t-1.
$$

每对图像保存真实 Δt。若仅 T=2，则只有一个相邻光流场，本轮不做“多光流时间建模”的结论；改变窗口长度须作为后续独立因素。

FB 使用同一已到达帧对的两个方向 `F(k→k+1)` 与 `F(k+1→k)`；所有 k+1≤t。反向光流不要求访问未来帧。

对 nuScenes，沿目标相机 `sample_data` 获取实际时间戳及对应位姿；区分相机采集与标注关键帧。12 Hz 相机和 2 Hz 关键帧不能混用。[R8][R9]

### 3.3 标签生成验证

不得仅用“位移÷帧间隔”作为完整速度定义。必须在以下已知运动上检查标签代码：

1. 直线匀速：分量和单位正确。
2. 无侧滑圆周运动：正确参考点的瞬时侧向速度为零，不因端点朝向与区间位移混用产生伪侧向。
3. 已知侧移：正负方向、幅值正确。
4. 已知旋转与相机杆臂：能区分相机点速度和目标点速度。

例如恒前向速度 U、横摆角速度 r 时，区间位移在起点系中的横向弦分量为：

$$
\tilde v_y=\frac{U(1-\cos(r\Delta t))}{r\Delta t},
$$

它不是该无侧滑参考点的瞬时侧向速度。区间标签可用明确的中点表达或刚体 twist；瞬时标签须用定义一致的微分／拟合，并报告误差与平滑影响。

两点差分对位置误差敏感。应比较若干合理差分间隔和拟合窗口，并在训练／验证数据上确定标签处理；不得在测试集上选择最有利时间偏移。

### 3.4 输入、标签和评价信息隔离

为每个数据字段记录四种角色：`inference_input`、`training_supervision`、`evaluation_only`、`split_metadata`。

- 推理输入不含真实位姿、真实旋转、CAN／IMU／GNSS。
- 评价可用真值划分工况，但不能据此选择模型输出或修正估计值。
- 训练几何损失若使用真值旋转，必须列为训练监督。
- 分割／法向／深度真值不能偷偷替代部署时的视觉估计；真值辅助诊断单列为理想条件实验。

### 3.5 数据划分与预处理

按完整 scene／log／采集路线划分，避免相邻重叠窗口跨集合；条件允许时另留新路线或新相机设置。保存清单和哈希，统计量只用训练集，阈值和模型选择只用验证集。

光流预处理约束：

- 保存带符号数值 u、v，不以伪彩色图替代主输入。
- 不逐张按最大幅值归一化；训练集统一标准化时保存统计量。
- resize 同时变换坐标与向量；crop／resize 同步更新 K 和掩码。
- 从 S0 起检查 NaN、Inf、越界、时间倒序、重复帧和异常时间间隔。
- 全窗口增强必须保持时间与几何一致；完整定义镜像标签和外参之前，几何实验禁用水平翻转。
- 固定光流权重、方向、单位、原始／输出分辨率、迭代数、缓存生成版本。

## 5. S0：先做必要核验，其余审计同步补齐

### 5.1 正式可比较训练前的最小核验

1. 核对当前数据的 vx/vy、坐标、参考点、单位、时间和标签模式；检查生成代码或已有可信记录，必要时用第 3.3 节的已知运动验证。明显的伪侧向或错位标签先修复。
2. 固定按场景划分的数据清单；核对当前实验所需的真实图像、标签、Δt，以及启用光流时的配对、方向与缩放。FB 实验另核对反向流，图像模型不等待流缓存。检查字段，排除真值误入推理输入。
3. 核查 ImageXY 和拟复用模块的实际计算图；确认原始带符号光流不会被 CMA 绝对时间差分替代。官方 FlexiNet 不能直接当作“无差分 RGB 基线”。[R1]
4. 选定首轮主指标、选模规则、初始化／更新政策与资源预算；记录基本侧向分布和零侧向误差。没有可信的最小改善阈值时，首轮先估计波动，再在后续确认实验前锁定，不能按有利结果反推阈值。

上述核验针对使实验失去意义的错误，不要求先完成全面审计报告。期间可并行实现 S2、整理配置及做合成／小样本检查；相关前提通过后即可启动正式训练。

### 5.2 可与 S1／S2 并行的工作

复现／重训图像基线，保存逐场景预测；补充标签误差与不同差分窗口分析、详细工况统计和历史结果溯源。有可用几何代码和标定时开展 G0；没有时单独安排，不阻塞 S2。

### 5.3 输出与完成判断

输出：`label_contract`、数据清单、输入／监督字段表、计算图、基线配置、预测与评价文件。

可以沿用仓库现有文件格式，不强制新建一套审计系统。完成判断：数据与标签有可追溯定义，模型输入符合边界，基线能重现或重训；不把尚未量化的标签精度当作已知真值精度。若仅具备代理标签，可以继续代理任务实验，但所有结果明确标记 `PLANAR_PROXY`。

## 6. S1：光流表示与图像基线对照（与 S2 同步）

### 6.1 先复用，再按需要补齐统一对照

**当前先复用通过核验的 ImageXY 作为项目图像基线。** 它即使含内部帧差，仍可作为有效的“仅图像输入模型”，但名称和结果中写清，不能称为无差分对照。Astra 不必先重写统一主干才能开始 S2。

同期实现简单图像＋光流对照和 flow-only。简单融合可采用原始通道早期拼接，或已有代码中计算图清楚的轻量特征拼接；先选择容易实现且可解释的一种。不同融合位置必须分别命名。它应与 S2 的新增因素可区分，例如简单光流投影对比独立空间／时间编码；若两者实际计算相同，合并为同一实验，不能包装成两种方法。

若要进一步隔离“表示”本身，可补充以下统一主干对照：输入适配层 → 空间特征 → 固定时间模块 → 池化 → 单一二维头，主干内部不隐式执行 CMA 差分。它是机制分析工具，**不是启动当前训练的强制重构任务**。

一个明确可执行的早期融合方案为：图像通道数 c（RGB 为 3、灰度为 1），L=T−1，批量 B；P_k=cat(I_k,I_{k+1})、D_k=I_{k+1}−I_k。每个时间步对应一对图像。

| 实验 | 每个帧对的输入 | 批量张量形状 |
| --- | --- | --- |
| S1-A | P_k | B×L×2c×H×W |
| S1-C | cat(P_k,D_k) | B×L×3c×H×W |
| S1-D_early | cat(P_k,F_k) | B×L×(2c+2)×H×W |
| S1-E | F_k | B×L×2×H×W |

选择该早期融合方案时，输入适配层将不同通道数投影到同一宽度，之后使用相同空间／时间架构和二维头，各组独立训练。S1-D_early 在空间编码前拼接，S2 对比独立编码后的融合。各组使用同样的源图像与时间跨度，适配层造成的参数差别仍需记录。若采用轻量特征融合，命名为 S1-D_light，同步调整配置与实验说明，不机械套用本表张量形状。两种简单融合首轮择一即可；下文 S1-D／D 泛指已明确选定的一种，R01 与 S2-E0 指向该实际配置。

**时间条件需要公平控制。** 若复用的图像基线不支持 Δt 输入，首轮可在预先规定容差的近固定间隔数据上比较，并保留真实时间戳及异常处理，不必为复测权重强改网络。若间隔变化明显，则给相关对照一致提供时间条件；一个可行方案是在空间编码后、时间聚合前接入 Δt_k/Δt_ref 标量或广播通道，Δt_ref 预先固定。给旧模型新增输入需要相应训练，不能直接拿不兼容权重评价。因工程复用暂时无法匹配时间输入时明确标为系统比较，后续补齐，不能把额外时间信息的收益归因于光流结构。

| ID | 输入／结构 | 主要检验 |
| --- | --- | --- |
| S1-A | 图像序列 | 无显式光流的表示基线 |
| S1-B | 容量／预算匹配的图像模型 | 容量影响；若 A 与 D 已充分匹配可合并 |
| S1-C | 图像＋固定定义的帧差 | 简单时间变化表示是否足够 |
| S1-D_early 或 S1-D_light | 图像＋正确配对数值光流；早期融合或轻量特征融合，首轮择一 | 显式光流系统的增益；明确实际融合位置 |
| S1-E | 仅数值光流 | 光流通路的可预测性 |

首轮选择一种帧差定义并固定，例如带符号 `I(k+1)−I(k)`；若要研究绝对值影响，另开实验，不能混称帧差。光流本身不经过 CMA 的再次绝对差分。

### 6.2 训练控制

- 固定 RAFT；各组使用相同图像、标签、划分和训练／选模预算。
- 记录 checkpoint 的训练来源、哈希和可能的数据重叠；不能用“下游参数一致”宣称总资源完全公平。[R13]
- S1 的基础对照不加可靠性研究模块、复杂注意力、地面补偿或几何损失；合法性预处理始终开启。S2 的可靠性实验可同期训练。
- 不只在测试时把光流置零。表示比较以各方案重新训练后的性能为主。
- 可在结论仍不清楚时增加另一冻结光流估计器；该对照同时改变质量与先验，不能完全拆分二者。

### 6.3 如何使用结果

S1 与 S2 可以同时启动；不要求 D 先胜过 A／B／C。简单融合不佳，也不能单独证明独立编码无效。首轮先判断 S2 相对现有图像基线是否有工程收益；容量、初始化、输入编码等不一致时，明确尚不能把全部收益归因于光流。

后续用 A／B／C 以及第 8 节控制逐步解释收益。若 D 与 C 接近，说明简单时间表示已能解释较多收益；若只有同路线改善，结合数据分析和可用的 G0 检查尺度与场景依赖。合理训练并排查输入质量后，若光流方案仍无稳定增益，保留阴性结果；没有必要无限增加模型复杂度。

## 7. G0：独立建立几何诊断基线（可并行，不阻塞 S2）

要做什么：给学习结果提供可解释的几何参照。怎么做：优先核对补偿工程／V3 中可复用的求解器，再按下面模型验证；已有标定和代码时可同步开展，资源有限时排在首轮 S2 之后。G0 是 G1 的必要准备，不是 S2 的启动条件。

### 7.1 首版可执行模型

首版命名为 **G0-C0：平面几何基线**。已知固定标定和米制相机高度，使用可信道路区域光流，联合求解平面参考点速度 `(v_x,v_y)` 与横摆角速度 `ω_z`。**不施加 v_y=0。**

该版本限定于平面道路、足够静态纹理、固定车体—相机外参及可接受的垂向／roll／pitch 变化。它用于诊断，不预先承担所有困难工况。

定义 q 为原点 O 的平面航向坐标系，`T_qc` 为相机坐标到 q 的变换；仅在相机相对 q 的姿态近似固定时使用固定标定。区间内平面 twist 近似恒定：

$$
\xi_q=(v_x,v_y,0,0,0,\omega_z).
$$

由参考点的平面运动构造静态点的相机间坐标变换：

$$
T_{c_{k+1}\leftarrow c_k}
=T_{qc}^{-1}\exp(-\widehat\xi_q\Delta t_k)T_{qc}.
$$

此式以明确的恒 twist 假设处理有限旋转与参考点偏置。q 与真实车体坐标 b 不必重合；固定 roll／pitch 只使相对变换可近似固定。`PLANAR_PROXY` 在 q 中评价，`BODY_3D` 则需要可靠的 q 到 b 转换与完整运动条件，不能直接把两种标签互换。

若相机相对 q 的姿态变化且具有可信估计，应使用 `T_qc(k+1)^−1 exp(−ξ̂_q Δt_k) T_qc(k)`；不能继续套固定共轭。若改用小运动线性化求解，应标出近似范围，并与有限变换在合成运动上比较。

源帧道路平面 `n_k^T X=d_k`、`||n_k||=1`，深度为：

$$
Z_k(p)=\frac{d_k}{n_k^\top K_k^{-1}\tilde p}.
$$

通过相机间变换投影获得预测光流，以鲁棒残差拟合运动。明确 n、d 的方向／符号，剔除深度非正、近地平线分母过小和模型外像素。

### 7.2 分解诊断

按以下顺序检查，避免直接用最终速度误差解释全部失败：

1. 合成地面＋真值光流：验证符号、坐标、横移与旋转能否区分。
2. 合成或有对应真值的图像＋预测光流：检查前端误差传播。
3. 实际道路＋固定先验：报告误差、失败与有效像素分布。
4. 在验证集扰动高度、法向、内参、Δt 与外参：确定主要敏感项。扰动范围按实际标定不确定性设置；无依据时标为示意压力测试。

另记录运动求解的数值条件、空间覆盖和残差。高度或深度缩放改变公制结果，不可用测试真值重新对齐尺度。

### 7.3 F_R／F_RC 的纳入条件

旧 F_R／F_RC 只有在模型、输入和输出契约核对后，才与新 C0 并表；不自动重命名为相同算法。

若继续研究视觉 roll／法向补偿：先定义估计器及量的物理含义。视觉重力方向不直接当作道路法向；固定 pitch 和高度的 roll 修正只作为受限对照。[R7][R11]

加入 full roll／pitch／垂向运动必须获得额外可信约束并审计可观测性，不能只在平面模型里增加自由参数后宣称已解决颠簸或侧倾。

### 7.4 完成条件

获得可复现的适用域与失败诊断，不要求 C 路线胜过学习模型。G0 结果用于决定是否值得引入几何损失、法向估计或公制深度。

## 8. S2：独立光流编码与可靠性处理（当前主任务）

### 8.1 独立光流编码候选

要做什么：让数值光流通过自己的编码器进入速度模型，并检验它比简单融合更有用与否。怎么做：复用已核实的图像编码器及训练接口，新增光流支路、简单融合和统一二维头；优先用配置切换实验，不复制多个不一致的训练脚本。

保留一组最终速度输出：

$$
h_I=E_I(I),\quad h_F=E_F(F),\quad
\hat v=G([h_I,h_F]).
$$

推荐首版光流分支：逐流场空间 CNN → 简单时间卷积（例如时间核 `(3,1,1)`）→ 池化／投影。保留符号及幅值，时间聚合前保留必要空间结构。Astra 可根据窗口和已有网络调整编码形式，但先保持简单，并说明相对简单融合增加了什么。最终向量拼接只说明特征融合，不声称进行了像素匹配。

比较：S2-E0 对应已选定的 S1-D 简单融合；S2-E1 使用独立分支；S2-E2 为独立分支去掉时间模块。尽量匹配参数和预算，固定初始化类别和可训练范围。若独立分支使用冻结预训练图像主干，而早期融合只能从头训练，这可作为工程系统比较，但不能直接归因于独立编码；后续补匹配训练条件的对照，不为追求形式一致而阻塞首轮运行。若只有一个光流时间步，不做多光流时间模块比较，也不为套用时间卷积默默增加窗口。

### 8.2 FB 提示与硬筛选分开

在同一帧对上：

$$
e_{FB}(p)=\|F(p)+B(p+F(p))\|.
$$

固定像素阈值可作初始基线，另在验证集比较相对＋绝对阈值形式：[R10]

$$
e_{FB}^2<\alpha(\|F\|^2+\|B_{warp}\|^2)+\beta.
$$

| ID | 处理 | 目的 |
| --- | --- | --- |
| S2-R0 | 仅基础合法性检查 | 原始参照 |
| S2-R1 | 原始光流＋FB 提示，首轮建议二值一致性掩码 | 可靠性提示是否有用 |
| S2-R2 | 不可靠流固定置零＋与 R1 相同的提示 | 在相同提示条件下，硬屏蔽是否更好 |

三组重新训练下游模型，从同一初始化政策分别启动，可以并行或排队，不必等 R0 训练完才开发 R1／R2。S2-E1 与 S2-R0 若配置相同就是一次实验，对应第 14 节 R03；S2-R1／R2 对应 R04／R05。首轮建议 R1／R2 输入同一 FB 二值掩码，唯一处理差异是是否置零不可靠流。连续残差提示可另设候选；若自主改用残差，比较硬屏蔽时仍保持提示表示和筛选规则一致，避免同时改变两个因素。

无论是否启用 FB，越界、NaN／Inf 与无效采样都要处理，不能作为可关闭的可靠性消融。不合法位置的填充值和有效掩码明确记录。参数差异需记录；必要时增加恒定提示通道控制。FB 阈值用预先设定的起点或验证集选择，记录保留比例及不同工况分布；双向光流均由当前已经到达的帧对计算。

可靠性不必等独立编码器胜出才做。如果 S1 已显示主要问题是遮挡，可先在简单模型上比较 R0—R2。若编码器与掩码均有希望，补“编码器简单／独立 × 提示关／开”的 2×2，检查交互。

### 8.3 静态、道路与低纹理的后续处理

低纹理、道路与动态物体处理各自建立独立 ID，不一次全加。对学习分支，先比较提示与硬删除；对几何分支，必须区分：合法对应、匹配可靠、静态背景、符合地面模型。

车辆语义不等于动态物体；静态建筑也不等于地面。若使用分割模型，登记其预训练来源、失败方式及推理成本，不能在最终测试换用真值掩码。

### 8.4 完成条件

本轮交付：可训练的独立光流编码模型，不加 FB／FB 提示／硬筛选的配置，相关基线结果，以及可以复跑的训练和评价命令。新增模型各组至少完成一次有实际学习过程的正式训练与验证；已有兼容且来源可信的图像基线可直接复测，不要求重复训练。若因资源不足未完成，分别标注未开始／运行中／完成／失败，不把启动训练当作训练完成。

研究判断：保留改善验证误差／泛化且计算代价合理的方案；无收益时可回退简单表示，同时记录原因。报告掩码覆盖和失败，不以掩码比例越低作为质量更高的证据。多种子确认及完整机制消融按后续安排补齐，不要求单次初筛直接给出最终论文级结论。

## 9. S3：只针对已识别短板增强结构（可选）

要做什么：在 S2 结果揭示具体短板后研究更好的编码与融合。怎么做：从下面选与问题对应的一个主要变化，与当前最好简单方案比较。候选范围继续保留，不要求首轮 S2 全部实现。

原计划阶段 02 与 04 的时序结构搜索合并在这里管理，避免把“简单时间卷积”和“MFE”当成不同理论层级。

| 候选 | 必须写清的新增因素 | 必需对照 |
| --- | --- | --- |
| SFE 式空间编码 | depthwise／空洞卷积／感受野变化 | 参数与感受野尽量匹配的普通空间 CNN |
| MFE 式时序编码 | 初始 3D 核、时间核、层数、宽度、池化位置及时间感受野 | 当前简单时间模块 |

| 特征加权 | 通道／空间权重，单一最终速度头 | 简单拼接 |
| 空间交叉注意力 | 保留多 token、位置与时间对应 | 简单融合与匹配预算模型 |

约束：

- 每路已全局池化为单个 token 时，不以交叉注意力宣称跨位置选择。
- 固定输入、可靠性规则、损失和训练政策，每次只替换一个主要运算。
- 若当前拼接方案已经满足目标，可直接跳过本阶段。

## 10. G1：闭合后再引入几何约束训练（可选）

要做什么：检验可解释的几何约束能否帮助速度学习。怎么做：等 G0 验证模型及变量来源后，在锁定学习基线上添加可关闭的几何损失，先小权重试验，再比较误差和敏感性。本轮 S2 不以完成 G1 为前提。

### 10.1 进入条件

必须同时满足：G0 已验证相应模型；主学习模型稳定；困难工况存在可解释的系统误差；尺度与几何量来源齐全；存在足够满足假设的训练区域。

训练前填写：

| 项目 | 来源、单位与适用域 | 固定／可训练／仅训练可用 |
| --- | --- | --- |
| K、畸变、图像几何 | 必填 | 必填 |
| Δt 和速度时间语义 | 必填 | 必填 |
| 相对旋转或角速度 | 必填 | 必填 |
| 速度到相对平移的生成方式 | 必填 | 必填 |
| 垂向与 roll／pitch | 明确建模或受限忽略的条件 | 必填 |
| Z 或 n、d 及米制尺度 | 必填 | 必填 |
| O 与相机的外参／杆臂 | 必填 | 必填 |
| 静态／道路／可靠掩码 | 必填 | 必填 |
| 梯度路径与失效规则 | 必填 | 必填 |

空缺不能用“之后再加姿态监督”代替。条件不具备时暂停 G1，不影响其他已完成阶段。

### 10.2 辅助几何量来源选一条

1. **训练标签构造**：有可信完整或受限平面运动标签时，旋转等作为固定量构造训练损失；推理不使用它们。登记额外训练信息。
2. **冻结纯视觉估计器**：由图像提供旋转／深度等，记录偏差、成本与失效。不能当作真值。
3. **辅助预测头**：预测旋转或必要的其他运动量。主任务仍是一组二维速度；有／无几何损失对照保留相同辅助头和监督。

若仅使用训练真值旋转作为损失输入，去掉几何损失后没有同样的监督通路；应明确归因边界，并做真值／视觉估计旋转和扰动敏感性比较，不声称完全隔离额外监督。

### 10.3 几何损失

**首版只约束最后一对图像 `(I_{t-1},I_t)`，不把窗口末端的一组速度用于解释整个窗口。** 令 k=t−1，源帧深度、平面和掩码均属于 I_k，观测流为 F(k→k+1)，Δt 取这对图像的实际时间差。以已验证的变换模型产生理论光流：

$$
\widehat F_k(p)=\pi\!\left(K_{k+1}
[R_{k+1\leftarrow k}Z_k(p)K_k^{-1}\tilde p+t_{k+1\leftarrow k}]
\right)-p.
$$

$$
\mathcal L_{geo}=
\frac{\sum_p M_{t-1}(p)\rho(F_{t-1}(p)-\widehat F_{t-1}(p))}
{\sum_p M_{t-1}(p)+\epsilon}.
$$

M 为满足当前模型的合法、可靠、静态区域；使用地面深度时还要满足地面条件。有效像素不足的窗口跳过几何项并记录，不允许通过全零掩码获得看似较低损失。

**输出的时间语义也必须匹配。** 若 S0 已选最后帧对的等效 twist 分量，可按同一约定构造区间运动；它不自动等于终点瞬时速度。若主任务仍为瞬时 v(t)，用它构造最后区间运动属于短区间恒 twist 近似，须先验证加减速工况下误差，并限制该几何项的适用范围；近似不满足时不启用 G1。不得只在 G1 改变标签来制造收益。若将来约束全窗口，须新增逐帧对运动输出或有定义的轨迹积分，并作为独立结构实验比较。

$$
\mathcal L=\mathcal L_{vel}+\lambda_{geo}\mathcal L_{geo}.
$$

光流是带噪估计，故该项不是独立真实光流监督。冻结 RAFT；先使用固定几何来源和掩码，不同时训练深度、法向、掩码、光流和速度全部模块。带噪几何先验可能产生负迁移。[R6]

### 10.4 最小实验

| ID | 配置 | 检验 |
| --- | --- | --- |
| G1-A | 锁定学习基线，λ_geo=0 | 参照 |
| G1-B | 同一模型＋固定小权重几何项 | 几何约束初始作用 |
| G1-C | 验证集权重敏感性 | 增益是否稳健；不是新增架构 |
| G1-D | 几何先验扰动／来源对照 | 对旋转、法向、尺度误差的敏感性 |
| G1-E，适用时 | 同辅助头与监督，去掉几何项 | 区分辅助任务和一致性项 |

各组保持相同可训练参数集合；若先只训练融合头，之后解冻编码器应另设训练策略实验。比较速度误差而非只看几何残差，检查非零侧向峰值和时间延迟是否受损。

### 10.5 完成条件

几何项在验证集上稳定改善目标指标且不损害关键工况才纳入；否则保留独立 C 路线和负结果。真实侧倾／颠簸不满足当前几何假设时，不把未改善解释为几何理论无效。

## 11. 统一训练策略

### 11.1 基础损失

$$
\mathcal L_{vel}=
\lambda_x\operatorname{SmoothL1}_{\beta_x}
\left(\frac{\hat v_x-v_x}{s_x}\right)
+\lambda_y\operatorname{SmoothL1}_{\beta_y}
\left(\frac{\hat v_y-v_y}{s_y}\right).
$$

该配方是工程起点，不是文献证明的唯一选择。s_x、s_y 用训练统计或预先固定的物理尺度，设置正下限；避免接近零的侧向分布导致过度放大标签噪声。β 和权重的单位／归一化约定写清，模型输出和最终评价仍为 m/s。

可在 S0／S1 固定前比较简单 L1 或未归一化损失；后续架构实验不同时改变损失。

### 11.2 冻结与微调

| 组件 | 默认 | 可选变化 |
| --- | --- | --- |
| RAFT | 固定权重、固定推理设置 | 不在首轮微调 |
| RGB／图像编码器 | 各架构对照使用同一初始化与更新政策 | 单独比较冻结与联合微调 |
| 光流编码器 | 在相应实验中训练 | 固定后研究融合，或单独联合微调 |
| 融合层与二维头 | 训练 | 不以未训练随机新头结果评价架构能力 |
| 几何辅助量 | 按 G1 来源表固定 | 新预测头或新监督作为独立因素 |

如果选择“冻结 RGB、训练光流与头、再微调”，应给每一步独立 ID，并对两个待比较架构采用同样政策。冻结还应明确 BatchNorm 统计与 Dropout 模式，不能仅设置梯度开关。

优化器、训练轮数／步数、学习率计划、早停、模型选择指标和种子在阶段前锁定；不同模型允许合理调参，但调参预算须一致并记录。

## 12. 评价、工况和最终测试

### 12.1 首轮与完整评价

首轮先输出 vx／vy 的 MAE、RMSE、平均偏差、零侧向基线，以及逐场景预测与指标；检查少量代表性工况和明显退化。独立编码／可靠性比较同时记录参数、训练设置和掩码覆盖。先建立统一入口，让已完成实验可直接并表。

下面保留完整评价要求，随研究补齐；其中多种子、场景不确定性、完整时延与跨域测试主要用于最终候选。缺少某种工况或新相机数据时写明局限，不虚构测试，也不因此停掉其他可用实验。

- v_x、v_y 各自 MAE、RMSE、平均偏差、95% 绝对误差分位数。
- 二维速度向量误差、速度大小误差，作为补充而非替代分量指标。
- 零侧向基线；可靠标签下的非零侧向子集，正负方向和幅值区间。
- 每个工况的样本数、场景数、持续时间；数据不足时不作强结论。
- 逐场景指标与全帧汇总；最终候选的训练种子波动及场景成对比较区间。
- 时间响应、峰值衰减、输出延迟；不允许测试时寻找最优时间平移再作为主结果。

### 12.2 工况定义

转弯／变道、高横摆、非零侧向运动、侧倾相关场景、低纹理、模糊、遮挡、动态对象、光照／路线／相机变化分别标记。变道不自动归为非零 v_y；视觉或元数据工况规则应可复现。

各阶段优先分析当前数据中有代表性的工况，逐步补齐，不能等最终测试才检查系统性失败。使用真值划分评价子集时，不把划分结果输入模型。

### 12.3 几何路线与学习路线的比较

统一坐标、参考点、时间、单位和标签版本。列出各自尺度／标定先验，必要时增加学习模型获得相同固定先验的对照；不因推理都叫纯视觉就宣称输入条件相同。

至少报告三张表：

1. 各模型在全量任务上的覆盖率、失败率及失效定义。
2. 共同有效集合上的成对精度，注明该集合限制。
3. 若部署要求每帧输出，报告预先定义的纯视觉／历史回退策略的全量结果。

没有回退时如实报告缺失，不把失败帧从主结论中消失。VO 对照不得使用测试真值进行尺度对齐后再声称有独立公制测速能力。[R4][R6]

### 12.4 系统成本与因果性

报告总参数、可训练参数、显存、吞吐、稳态延迟和首次窗口等待。包含光流双向计算、分割／深度／视觉姿态等所有启用模块；缓存条件另列。

严格在线模式不得使用整视频统计或未来图像。若借鉴 OpenVO，替换其整视频内参平均为固定标定或仅历史估计，并核对具体实验是否使用双目深度。[R5]

### 12.5 S4：最终锁定与独立测试

验证集确定全部结构、超参数、阈值和权重。最终补充关键 2×2 交互，以及对保留模块的移除重训；无需对所有候选做全因子。

锁定代码、模型和评价配置后，才运行独立测试。若据测试结果再次设计模型，本轮测试不再作为未见开发过程的独立证据；需要新的留出数据或如实披露。

### 14.4 偏差处理与停止规则

- 发现计划与实际源码／数据矛盾：优先修正有证据的错误，更新配置、记录影响并继续可执行工作。
- 某组训练失败：先检查数据、数值和优化；单次失败不等于该方法无效，不立即取消整个光流方向。

- 标签或时间定义未通过：暂停解释侧向算法收益。
- 光流无稳定收益：排查后形成结论，保留图像模型，不强行扩分支。
- 独立分支不胜简单融合：保留简单融合。
- 筛选损害关键工况：改提示方式或撤销。
- MFE／加权／注意力无稳定收益：撤销，不将复杂度当成果。
- 几何模型不闭合：不启动 G1。
- 几何约束产生负迁移：限制适用域、减弱或撤销，保留诊断结果。
- 测试集不用于决定哪一模块留下。

7. 对最终任务与代理任务的清楚区分，列出尚不能证明的真实侧滑／三维体轴能力。

## 15. 关键文献与核验定位

本节编号仅用于本修订计划；详细讨论见配套审查报告。

- **[R1] FlexiNet，IEEE Access 2025**：[论文 DOI](https://doi.org/10.1109/ACCESS.2025.3562229)；[作者接受稿](https://www.researchgate.net/publication/390936145_FlexiNet_An_Adaptive_Feature_Synthesis_Network_for_Real-Time_Ego_Vehicle_Speed_Estimation)；[固定提交 modules.py](https://github.com/Geekgineer/FlexiNet/blob/e25127f6912733213d46881d1139c9632e2f0114/model/modules.py)、[主计算图](https://github.com/Geekgineer/FlexiNet/blob/e25127f6912733213d46881d1139c9632e2f0114/model/FlexiNet.py)。依据：CMA 差分、SFE／MFE 算子、AFT 权重；原论文主要是标量测速。
- **[R2] Deng & Peng，Vision-based Vehicle Ego Velocity Estimation，2023 硕士论文**：[大学全文](https://odr.chalmers.se/bitstreams/2e3447c3-6fa0-46a1-8538-df52c78771be/download)，§4.1—4.2、§5.2、表 5.1—5.2。依据：直接纵／侧分量与表示比较；光流分支不是最优，不能预设增益。
- **[R3] 3DCMA，CVPR SSAD Workshop 2023**：[全文](https://trust-ai.github.io/SSAD2023/assets/papers/7.pdf)，§3 与消融。依据：图像时序与车道提示；输出标量速度。
- **[R4] ZeroVO，CVPR 2025**：[正式页](https://openaccess.thecvf.com/content/CVPR2025/html/Lai_ZeroVO_Visual_Odometry_with_Minimal_Assumptions_CVPR_2025_paper.html)、[终稿](https://zvocvpr.github.io/resources/CAMERA_READY.pdf)，§3、表 1—2。依据：尺度、几何表示与融合；不是直接二维速度误差证据。
- **[R5] OpenVO，CVPR 2026**：[正式页](https://openaccess.thecvf.com/content/CVPR2026/html/Nguyen_OpenVO_Open-World_Visual_Odometry_with_Temporal_Dynamics_Awareness_CVPR_2026_paper.html)、[已核验 arXiv v1](https://arxiv.org/html/2602.19035v1)，§3.1—3.2、§4.3、补充 §9。依据：时间条件与几何先验；需审计整视频内参和 stereo 配置。
- **[R6] RoMeO，2024 首发、2025 v3 预印本**：[全文](https://arxiv.org/html/2412.11530v3)，§3、§4.2、表 4。依据：公制深度与鲁棒几何；带噪先验可能负迁移。按本次核验版本引用，不推定会议归属。
- **[R7] Freespace Optical Flow Modeling for Automated Driving，TMECH 2024，online 2023**：[全文](https://www.ruirangerfan.com/pdf/tmech2024_feng.pdf)，§III-A／III-B、§V-B。依据：地面光流；保留无侧滑假设及合成位姿反求的证据边界。
- **[R8] nuScenes 官方 schema**：[文档](https://github.com/nutonomy/nuscenes-devkit/blob/master/docs/schema_nuscenes.md)，`ego_pose`、`sample_data`、`calibrated_sensor`。依据：二维定位、z 恒 0、时间与标定字段。
- **[R9] nuScenes，CVPR 2020**：[正式论文](https://openaccess.thecvf.com/content_CVPR_2020/papers/Caesar_nuScenes_A_Multimodal_Dataset_for_Autonomous_Driving_CVPR_2020_paper.pdf)，表 2 与数据标注节。依据：相机 12 Hz、关键帧 2 Hz；硬件指标不等于差分速度标签误差。
- **[R10] UnFlow，AAAI 2018**：[全文](https://arxiv.org/pdf/1711.07837)、[作者损失实现](https://github.com/simonmeister/UnFlow/blob/master/src/e2eflow/core/losses.py)，式 (1)。依据：双向一致性与遮挡检查，不证明静态性。
- **[R11] GeoCalib，ECCV 2024**：[全文](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/05636.pdf)，§3。依据：视觉标定／重力方向；不能自动解释为道路法向。
- **[R12] FUMET，ECCV 2024**：[全文](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/03328.pdf)。依据：车辆尺寸先验与高度一致性支持公制深度；不是测速论文。
- **[R13] RAFT，ECCV 2020**：[全文](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123470392.pdf)、[官方训练说明](https://github.com/princeton-vl/RAFT)。依据：光流前端与预训练；需登记实际 checkpoint。
