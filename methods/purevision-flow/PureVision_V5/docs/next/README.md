## 设计与自审

| 项目 | 实施安排 | 自审依据及限制 |
|---|---|---|
| 场景选择 | seed42 在原 train_core/dev 内按场景身份确定性排序，选 32/8 个场景；同一 selection 文件 | 不拟合 dev、不接触 holdout、不改变标签和原 manifest，保留选择身份及完整场景内窗口 |
| 分辨率 | RAFT 宽×高 512×288 与 1024×576 | 两者比例相同、FP32/12 updates/权重/预处理一致；不加 FB |
| 训练视图 | 两者统一宽×高 128×72 | u/v 分别乘 1/4 或 1/8；valid 同规则，不要求两种预测的 mask 数值相同 |
| 模型 | 原 R02 空间 CNN、四步时间卷积、64D 特征与二维头 | 不改模型计算或参数量，不借本轮引入 CMA/Flex/RGB/几何约束 |
| 训练协议 | seed42、40 完整 epoch、batch64、原 AdamW/loss、无提前早停 | 两组重新初始化并记录相同初始参数/样本排序证据；旧20轮成绩仅背景 |
| 缓存 | 旧512缓存核验后只读复用；1024先短批，再仅为所选40场景生成新版本 | native 与派生视图合同分开；不改旧缓存/不覆盖原始工件 |
| 资源 | 实测后GPU0/GPU2各生成一个互斥场景分片(batch8)；GPU1先低R02，再高R02；每卡一个任务 | 实测峰值显存/吞吐/磁盘，OOM只减少生成batch，不擅改1024目标尺寸 |
| 评价 | dev EPE选模、同dev重算、逐scene/两轴误差；train拟合vy中位数基线 | 侧向样本不足仍报告不足；不能从预试验直接推出统计显著性 |
