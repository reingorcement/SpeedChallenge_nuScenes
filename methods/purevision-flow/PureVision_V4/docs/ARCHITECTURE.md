# V4 实现边界

主流程为 RGB/固定标定 → RAFT 前后向一致性 → 路面支持 → 按序法向状态 → 每对有限位姿 → SE(3) 对数 → 相机杆臂转换 → 三对聚合 → 可选新融合头。

`io.py` 统一标定、像素中心变换、输入白名单和输出目录约束。相机速度与协方差通过同一个 6×6 Jacobian 转换到标定参考点：`v_ref = C v_camera − (C omega_camera) × lever`。完整三维转换后才取纵横向分量。

`geometry.py` 用原有限求解作为可追溯的数值核心，增加残差门槛、竞争平面位姿检查、协方差正定处理和帧对级数值异常捕获。语法或接口错误不会被无差别吞掉；无效输入形状仍抛出异常。

`normals.py` 保留原法向门限和 F_RC 约束，显式记录源帧坐标；增加时间间断、保持时长和连续性检查。法向只按序生成，不在 shuffle 的训练 loader 中共享状态。

`model.py` 将旧 RGB 特征提取器冻结，V4 使用独立修正/门控/不确定度头。旧门控不迁入 V4。诊断包含几何速度、协方差、条件数、残差、有效帧对模式、法向状态、dt 和测量延迟。所有几何无效时，新融合输出与直接分支完全相等。

`training.py` 从不修改冻结几何，训练读取独立标签。缓存完整性和 train/dev 重叠检查发生在训练开始前。当前是可实际训练的冻结特征阶段，不是可微有限求解器。

`nuscenes_export.py` 独立计算完整三维体轴标签，保留 ego-origin 参考点，输出新的标签文件，不更新 V3 缓存。中心差分使用非均匀时间间隔的二阶导数公式，序列端点使用二阶单侧公式。

`evaluation.py` 在输出帧时刻匹配标签，报告 own/common 有效集。全失效工况保留在覆盖率和失败工况数中，误差均值仅在有有效输出的工况上计算，并显式列出该工况数。

`_legacy/model/` 是 V3 原网络与必要几何依赖，仅改绝对导入前缀以隔离命名空间。`_reference/` 是补偿版有限求解、法向、路面支持和约束函数的副本；主程序没有对它们进行运行时替换。
